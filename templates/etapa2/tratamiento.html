Alcance de esta entrega

Esta seccion documenta que se haria y por que, no un resultado ya aplicado. No se ejecuta ningun script de limpieza sobre dataset_calidad_agua.csv, no se genera una version "despues" del dataset y no se presenta una comparacion antes/despues. La ejecucion del ETL queda para una etapa posterior del proyecto.

Criterio general para decidir el tratamiento

  1. Si la variable es central para la pregunta de investigacion (como irca), se prioriza no inventar dato sobre completar a toda costa.
  2. Si el problema es de forma y no de contenido (fechas, mayusculas, texto libre), se estandariza sin perder informacion.
  3. Si el problema es de duplicidad o de dominio invalido, se corrige contra una regla verificable (llave candidata, rango normativo), no por eliminacion arbitraria.
  4. Cuando la correccion podria ocultar un evento real (como los atipicos del ano de crisis 2024), se marca para revision manual en vez de aplicar una regla automatica ciega.
